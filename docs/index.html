📚 About This Documentation

This documentation is designed for developers, contributors, and AI agents working with the Arnis codebase. It provides in-depth technical information about the architecture, algorithms, and implementation details.

Whether you're fixing bugs, adding features, or just exploring the code, these guides will help you understand how Arnis works under the hood.

🎯 For Developers

Detailed technical documentation with code examples and best practices

🤖 For AI Agents

Structured information for automated code analysis and generation

🔧 For Contributors

Guides on adding processors, fixing bugs, and improving performance

📖 For Learners

Step-by-step explanations of complex algorithms and data structures

🎓 Learning Path

New to Arnis? Follow this recommended learning path:

  1. Start with Architecture: Get the big picture of how components fit together
  2. Learn Coordinate Systems: Understand the math behind geographic transformations
  3. Explore Element Processing: See how real-world features become Minecraft blocks
  4. Study World Generation: Learn about file formats and data serialization
  5. Read Agent Guides: Discover best practices and skill development paths

💡 Key Features of Arnis

Real-World Accuracy

Uses OpenStreetMap data for authentic geographic representation

Elevation Integration

Incorporates real terrain heights from AWS Terrarium tiles

Dual Edition Support

Generates worlds for both Java and Bedrock editions

Modular Design

Clean architecture with independent processor modules

Performance Optimized

Parallel processing and efficient algorithms for speed

Cross-Platform

Runs on Windows, macOS, and Linux
